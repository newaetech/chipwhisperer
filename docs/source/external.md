# External Contributions

This page highlights contributions to the ChipWhisperer ecosystem that live
outside of our repositories.

These are not NewAE products. We do not endorse them; we have not validated
them. We also definitely do not support them: contact their creators for
assistance.

If you have a project that you'd like to add to the list, tell us about in on
our [forum](https://forum.newae.com).

In alphabetical order:

## [Abductor](https://github.com/therealdreg/abductor)
*"The Abductor is an adapter board that lets you run CW312 targets on a
ChipWhisperer CW308 UFO."* 

Husky kits include an adapter board that lets you run CW308 targets on a CW313;
Abductor lets you go the other way.


## [ChipWhisperer Studio](https://github.com/keyuraghao/chipwhisperer-studio)
A GUI front-end for ChipWhisperer.


## [Glitchy](https://github.com/BitBangingBytes/Glitchy)
*"Glitchy is a no-code visual interface to the world of microcontroller glitching."*

Lets you visualize glitch shapes, and more.


## [Trace Adapters](https://github.com/google/scaaml/tree/main/PCBs)
Several PCB designs that facilitate using trace.
